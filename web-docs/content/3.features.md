FileManager is early work in progress: this is what it does in the current release.

## Views

- **Details, tree, list, medium / large / extra large icons**: switch with `Ctrl` + mouse wheel or from the info
  bar at the bottom right. View and sorting can be kept per folder.
- **Tree view**: expand folders in place. Only what is expanded is kept in memory.
- **Cover Flow**: pictures and videos in perspective over the details list, with reflections. Drag across the
  covers, use the wheel or the bar under them; filter all files, photos and videos, or photos only.
- **Native icons and thumbnails** of images and videos, loaded in the background into caches with a byte budget.
- **Preview pane** (`Alt+P`) with a large thumbnail and the file's details.
- **Instant filter** and sortable columns with natural sort.

## Tabs and windows

- Tabs with back / forward history.
- Drag a tab along the strip to reorder it, out of the window to detach it, onto another window (also of another
  running instance) to move it there. A preview follows the cursor and says what releasing will do.
- Address bar with breadcrumb; click its empty space to type a path, with folder autocompletion.

## Selection

Multiple selection as in Explorer: `Ctrl`+click, `Shift`+click, `Shift` / `Ctrl` + arrows, `Ctrl+A`, and a rubber
band dragged from the empty space, in every view.

## File operations

- Rename in place (`F2`); when the name is taken it offers a numbered one (`name (2).txt`), as Explorer does. Delete to the Recycle Bin (`Del`) or for good (`Shift+Del`), cut / copy / paste, new
  folder (`Ctrl+Shift+N`).
- Operations go through the Windows shell (`IFileOperation`), with its progress, conflict and confirmation dialogs.
- The clipboard works with Explorer both ways.
- Drag and drop with Explorer and other apps, both ways, and between windows: onto the file view, a folder, a tab,
  a favorite, a drive or a breadcrumb segment. Explorer's rules: move within a drive, copy to another one, `Ctrl`
  copies, `Shift` moves.
- The listed folder updates by itself when its content changes.

## Folder sizes

Off by default: turn them on in the settings. Then the size column shows the size of each subfolder of the listed
folder, computed in the background and only for that folder.

- Two worker threads walk the subfolders; the size grows while it is counted ("1.2 GB…") and the folder sorts by
  size like a file.
- Leaving the folder cancels the walk. Results are kept for 5 minutes in a small cache, and `F5` counts again.
- Symbolic links and junctions are skipped, and so are the exclusions (`.git`, `node_modules`, `Intermediate`,
  `DerivedDataCache` by default, editable in the settings): a size marked "≥" left something out.
- Nothing per file is kept in memory: one number per folder.

## Explorer integration

- A context menu in Windows 11's style: a row of icons for cut, copy, rename and delete, then open, "Open with",
  and every entry Explorer's menu has (what apps add, "Send to", "New"…), with their icons. Keyboard included.
- "Show more options", or `Shift`+right-click, opens Explorer's own menu, dark or light with the app.
- Shortcuts (`.lnk`) look like shortcuts; one to a folder opens it in the tab.

## Sidebar

Favorites and drives as collapsible sections, and the Recycle Bin below them. Add favorites from the context menu
or by dropping folders on the heading, reorder them by dragging. Resizable, and it collapses with `Ctrl+B`.

## Recycle Bin

Browse it inside the app: where each item was deleted from and when, restore, delete for good, empty it. Files
dropped on it go to the bin.

## Themes and languages

Dark, dimmed (five accent colors) and light; English and Italian. Everything switches at runtime from the
settings (☰ or `Ctrl+,`).

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `Enter` | Open the selected items |
| `↑` `↓` `←` `→` `Home` `End` `PgUp` `PgDn` | Move; with `Shift` extend the selection, with `Ctrl` move without selecting |
| `Ctrl+Space` | Select or deselect the item at the cursor |
| `Ctrl+A` | Select all |
| `F2` | Rename |
| `Del` / `Shift+Del` | Delete to the Recycle Bin / for good |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Cut / Copy / Paste files |
| `Ctrl+Shift+N` | New folder |
| `Alt+Enter` | Properties |
| `Backspace` / `Alt+Up` | Parent folder |
| `Alt+Left` / `Alt+Right` | Back / Forward |
| `F5` | Refresh |
| `Ctrl+T` / `Ctrl+W` | New tab / Close tab |
| `Ctrl+Tab` | Next tab |
| `Ctrl+N` | New window |
| `Ctrl+F` | Focus filter |
| `Ctrl+L` | Edit path |
| `Ctrl+H` | Show or hide hidden files |
| `Ctrl` + mouse wheel | Switch view mode |
| `Ctrl+B` | Show or hide the sidebar |
| `Alt+P` | Preview pane |
| `Ctrl+,` | Settings |

## Roadmap

- Bulk rename of a multi-selection (find / replace, numbering, case), with a preview
- Persistent tabs
- Search through the Everything SDK
- Remote sources (SFTP, NFS and other network storage) browsed like folders
