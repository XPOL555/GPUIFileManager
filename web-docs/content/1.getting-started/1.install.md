Every [release](https://github.com/XPOL555/GPUIFileManager/releases/latest) on GitHub ships the app in four
forms: two installers and two portable downloads. Windows 10 or 11, 64-bit.

| File | What it is |
|---|---|
| `filemanager-vX.Y.Z-windows-x64-setup.exe` | Setup (NSIS), per-machine: asks for admin, installs in `C:\Program Files\FileManager` |
| `filemanager-vX.Y.Z-windows-x64.msi` | The same as an MSI, for silent or managed deployment |
| `filemanager-vX.Y.Z-windows-x64-portable.zip` | The portable exe and the README, zipped |
| `filemanager-portable.exe` | The portable exe alone: no installation, run it from anywhere |

Both installers add an all-users Start menu entry and an entry in **Settings > Apps**, and a newer version
replaces the old one. Use one of the two, not both.

## Silent install

```sh
filemanager-vX.Y.Z-windows-x64-setup.exe /S              # add /D=C:\path to change the folder
msiexec /i filemanager-vX.Y.Z-windows-x64.msi /qn
msiexec /x filemanager-vX.Y.Z-windows-x64.msi /qn        # uninstall
```

## Settings

With the installers, settings are saved in `%APPDATA%\FileManager\settings.json` and kept on uninstall.
The portable exe keeps them next to itself (see below). Open them from the ☰ menu or
with `Ctrl+,`.

## Portable mode

`filemanager-portable.exe` (alone or from the portable zip) reads and saves `settings.json` in its own folder
instead of `%APPDATA%`, so the folder can travel on a USB stick. If that folder can't be written (for example
under `Program Files`), it falls back to `%APPDATA%\FileManager`. **About** in the ☰ menu shows where the
settings are.

From source, the portable exe is `cargo build --release --features portable`.

## Build from source

Windows and a recent stable Rust toolchain (edition 2024):

```sh
git clone https://github.com/XPOL555/GPUIFileManager
cd GPUIFileManager
cargo build --release     # target\release\filemanager.exe
```
